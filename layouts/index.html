Modules

Cinq modules de formation, chacun autonome ou combinable en parcours. Chaque module part d'une démo live, pas d'un diaporama.

M1 · Fondamentaux des agents IA

½ journée

Qu'est-ce qui change vraiment avec les agents ? Le socle commun de toute l'équipe, en mode décision + équipe.

M2 · Automatiser son quotidien

1 journée

De la démo au script de production : vos tâches réelles, automatisées chez vous, pas chez le formateur.

M3 · Pipeline autonome : ralph, beads & sous-agents

2 jours

Une boucle de développement qui travaille seule : base d'issues (beads), itération autonome (ralph), sous-agents qui se contrôlent mutuellement.

M4 · LLM & génération d'images locale sur GPU

1–2 jours

llama.cpp sur une carte 12–24 GB, service local avec API compatible OpenAI, Stable Diffusion avec contrôle (LoRA, post-traitement).

M5 · Audit d'agentisation & feuille de route

2–3 jours in-situ

Cartographier les flux, scorer ce qui est automatisable maintenant, chiffrer le gain, produire une feuille de route que la direction exécute sans moi.
