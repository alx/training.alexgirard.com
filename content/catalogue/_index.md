> Tous les ateliers sont **pratiques** : chaque
> module se termine par un livrable fonctionnel que les participants
> repartent avec. Aucun module n'est donné en mode « diaporama ».

### Combinaisons types

| Situation | Parcours |
|---|---|
| Décideur seul | M1 (½ j) → décision → M5 si « oui » |
| Équipe tech | M2 + M3 (3 j) → M4 en option |
| Équipe mixte (5–8 pers.) | M1 (½ j) puis M2–M5 sur 5 jours |
| ONG / association | M1 + M2, stack 100 % local |
